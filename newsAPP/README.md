# News App

Flutter application for browsing Indonesian news.

## Run in Chrome

Install Flutter and Google Chrome, then open a terminal in the `newsAPP` folder:

```powershell
flutter pub get
flutter run -d chrome
```

To launch with the VS Code debugger, open the `News_APP` folder as the workspace,
select **Launch News App in Chrome**, and press **F5**.

If dependencies have not been fetched yet, run `flutter pub get` from `newsAPP`
first.
